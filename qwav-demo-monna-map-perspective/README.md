## What the demo is for

The Monna map takes a point on the boundary of a Bruhat-Tits tree, written as a sequence of p-adic digits, and sends it to the real number whose base-p digits are the same sequence. A branching tree can then be read as the unit interval. Points that share more leading digits are closer in the tree's ultrametric and land in a smaller common subinterval.

QNFO treats the map in Ultrametric Physics module 11; the text is in the [publications of QNFO/.github](https://github.com/QNFO/.github/tree/master/publications/2026/04).
